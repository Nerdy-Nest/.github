# Nerdy Nest

Nerdy Nest is a mechanical keyboard store in Pakistan. We sell keyboards, keycaps, switches and accessories, and build custom keyboards to order.

We also make free tools for the boards we sell:

- **Custom Drive**: browser-based drivers for keyboards and macropads. Remap keys, record macros and change lighting with no software to install.
- **NerdLaunch**: a small Windows app that turns any key into a launcher for apps, folders, websites and commands. Private by design: no tracking, no network access.
